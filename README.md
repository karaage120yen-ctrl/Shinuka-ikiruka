# 死ぬか生きるかの戦い

競馬の育成ゲームです。馬が生まれてから引退するまでを育てて、騎手視点の3Dレースで勝負します。

**遊ぶ：** https://karaage120yen-ctrl.github.io/Shinuka-ikiruka/
（iPhoneはSafariで開いて「共有」→「ホーム画面に追加」でアプリになります）

## できること
- 🐎 馬の育成（サッカーやるよんと同じ流れ）：牧場レポート → 年の調教方針 → 2か月ごとに行動 → 出来事（成功率つきの選択）→ ターンの結果 → 年間総括 → 来年の路線 → 引退。0歳で誕生、2歳6月デビュー、7歳の年末か故障で引退
- 🏇 騎手の育成（同じ流れ）：スカウトレポート → 競馬学校2年 → 厩舎を選んでデビュー → 毎年の所属先オファー → 33歳から引退可・45歳で引退。暮らし（家・車・恋人・結婚）もある
- 📖 一覧：引退した馬・デビューした騎手
- 🎰 ガチャ：枠のみ（キャラは `dev/src/gacha.js` に追加）
- ⚔️ 対戦：育てた馬でG1などを走る。対戦コードで友達の馬とも勝負
- 🏁 レース：騎手の一人称視点。◀▶で進路、ムチで加速（体力が減りやすい）

## 作り方（開発用）
- ソースは `dev/src/`。`dev/build.sh` で `app.js` などを作る（Three.js をまとめて1ファイルにする）
