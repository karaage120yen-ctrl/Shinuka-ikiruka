# 死ぬか生きるかの戦い

競馬の育成ゲームです。馬が生まれてから引退するまでを育てて、騎手視点の3Dレースで勝負します。

**遊ぶ：** https://karaage120yen-ctrl.github.io/Shinuka-ikiruka/
（iPhoneはSafariで開いて「共有」→「ホーム画面に追加」でアプリになります）

## できること
- 出来事：馬・騎手それぞれ約2,000種類
- 🐎 馬の育成（サッカーやるよんと同じ流れ）：牧場レポート → 年の調教方針 → 2か月ごとに行動 → 出来事（成功率つきの選択）→ ターンの結果 → 年間総括 → 来年の路線 → 引退。0歳で誕生、2歳6月デビュー、7歳の年末か故障で引退
- 🏇 騎手の育成（同じ流れ）：スカウトレポート → 競馬学校2年 → 厩舎を選んでデビュー → 毎年の所属先オファー → 33歳から引退可・45歳で引退。暮らし（家・車・恋人・結婚）もある
- 🎫 競馬で賭ける：コインで馬券を買う。券種はJRAと同じ8種類（単勝・複勝・枠連・馬連・ワイド・馬単・3連複・3連単）、払戻率もJRAと同じ。出馬表（枠番・馬番・性齢・斤量・騎手・馬体重・印・オッズ・人気）、今月の実際の重賞がメイン。3D中継で観戦できる
  - ルーム：同じルームコードの人は出馬表・オッズ・結果が全員同じ。結果コードを送り合って順位を競う
- 🧬 配合：引退した牡馬×牝馬（または牧場の種牡馬・繁殖牝馬）から子どもを産ませる。能力・適性・脚質・毛色・特殊能力が遺伝し、何代でも血統をつなげられる（繁殖牝馬は6頭まで）
- 🌍 海外遠征：サウジC・ドバイWC・ドバイシーマ・キングジョージ・凱旋門賞・香港C/ヴァーズ（G1を勝つか重賞3勝で解禁）
- 🌦 天気と馬場：晴・曇・雨・雪、良・稍重・重・不良。競馬場ごとの見た目と坂（東京の長い直線、中山の急坂、京都の3コーナーの坂、海外のナイター・パリなど）
- 🎙 実況：レース中に文字で表示
- 🎬 カットシーン：誕生・デビュー・初勝利・G1・ケガ・引退などをドット絵で
- 🏆 実績と称号：30種類。達成するとにんじん・コインがもらえ、称号をホームに表示できる
- ☁️ オンライン（Firebase を設定したとき）：クラウド保存、ルームのみんなの馬券と収支がリアルタイムで見える、「みんなで一緒に見る」で同時に観戦
- 📖 一覧：引退した馬・騎手（血統表つき）
- 🎰 ガチャ：枠のみ（キャラは `dev/src/gacha.js` に追加）
- ⚔️ 対戦：育てた馬でG1などを走る。対戦コードで友達の馬とも勝負
- 🏁 レース：騎手の一人称視点。◀▶で進路、ムチで加速（体力が減りやすい）

## 作り方（開発用）
- ソースは `dev/src/`。`dev/build.sh` で `app.js` などを作る（Three.js をまとめて1ファイルにする）

## オンライン機能の設定（Firebase・無料）
設定しなくてもオフラインで全部遊べる。オンラインにしたいときだけ：
1. https://console.firebase.google.com でプロジェクトを作る（サッカーやるよんと同じプロジェクトでもOK）
2. 「Authentication」→「始める」→ ログイン方法で「匿名」と「Google」を有効にする
3. 「Authentication」→「設定」→「承認済みドメイン」に `karaage120yen-ctrl.github.io` を追加
4. 「Firestore Database」→「データベースを作成」→ 作ったら「ルール」タブに `firestore.rules` の中身を全部貼って「公開」
5. 「プロジェクトの設定」→「マイアプリ」→ ウェブアプリ（</>）を追加 → 出てきた `firebaseConfig` の中身を `firebase-config.js` に貼る
